      <h2>Course Introduction</h2>
      <p>
        The Bachelor of Technology (B.Tech) in Computer Science &amp; Engineering is a four-year
        undergraduate program focused on software development, algorithms, computer systems, and
        modern web technologies. Students build strong analytical fundamentals alongside practical
        laboratory and project work.
      </p>
    </section>

        <li>Database Management Systems</li>

      </ul>

      <h2>Admission Process</h2>
      <ol>

        <li>Participate in merit-list counseling and branch allocation.</li>

    <section id="syllabus-topics">
      <h2>Subject Syllabus Breakdown (Nested List)</h2>
      <p>Key modules covered in <strong>Web Technologies &amp; Markup Standards</strong>:</p>
      <ul>
        <li>
          Module 1: Web &amp; Internet Basics
          <ul>
            <li>How browsers, servers, and HTTP requests work</li>
            <li>Project folder organization and relative file paths</li>
          </ul>
        </li>
        <li>
          Module 2: HTML5 Document Structure
          <ul>
            <li>Semantic page landmarks (<code>header</code>, <code>main</code>, <code>section</code>, <code>footer</code>)</li>
            <li>Headings hierarchy and text formatting</li>
            <li>
              Lists and Media
              <ul>
                <li>Ordered, unordered, nested, and description lists</li>
                <li>Accessible links and responsive image attributes</li>
              </ul>
            </li>
          </ul>
        </li>
        <li>
          Module 3: Forms &amp; Accessibility
          <ul>
            <li>Semantic form controls and labels</li>
            <li>Screen-reader landmarks and keyboard navigation</li>
          </ul>
        </li>
      </ul>
    </section>
